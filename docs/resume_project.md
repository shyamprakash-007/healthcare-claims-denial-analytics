# Healthcare Claims & Denial Performance Analytics

**SQL | PostgreSQL | Tableau | Python | Pandas**

- Audited and prepared 1,000 synthetic healthcare claims, preserving identifier formatting and documenting status, outcome and AR review rules.
- Built a claim-grain SQL star schema with seven dimensions and 37 analyses covering denials, financial gaps, follow-up and service-month trends.
- Developed four interactive Tableau dashboards with shared filters, denial-reason actions and KPI reconciliation against SQL.
- Reconciled 20 KPIs between Python and PostgreSQL and all 37 query outputs across PostgreSQL and DuckDB; flagged 315 claims for status/outcome review without altering source labels.

Evidence: executed notebook and audits; SQL schema/query catalog; packaged Tableau workbook and native validation; backend reports and rulebook. PostgreSQL execution used embedded PGlite. This is a synthetic portfolio project, not healthcare employment or a claim of recovered revenue or realized operational improvement.
